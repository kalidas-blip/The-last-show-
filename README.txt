THE LAST SHOW - v2 (Godot 4.3, Android, landscape)

Build: put all files in the repo root (flat, no folders), keep .github/workflows/build-apk.yml, commit, download the APK from Actions > Artifacts.

Controls: left thumb = move, right side drag = look, RUN = sprint (loud), LIGHT = flashlight,
big red button = TAKE / STAB / HIDE / LEAVE / KILL / OPEN.
Hide in cabinets (HIDE prompt). The clown hears sprinting, investigates noise, and checks hiding places.

Story: find the knife, destroy 5 hearts, follow the crying, kill the clown, take the key, open the main gate.
Private use only: the clown model is based on a copyrighted character.
